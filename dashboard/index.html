These protocols already trade, so the board shows the market's own value for them and never ranks them by implied value. A launch already happened has nothing left to farm.

How the value is scored

implied = TVL × 0.30 × (1 + clamp(7d change, −50%, +150%) × 0.6) × (0.5 + min(age, 730 days) ÷ 730 × 0.5) × (1 + min(chains − 1, 4) × 0.03)

  • Base. A protocol's TVL times 0.30: what its token would be worth if the protocol's record stayed as it is.
  • Growth. Its seven-day TVL change, clamped, moves the base up or down by up to 90%.
  • Maturity. How long it has run, from half value when new to full value after two years.
  • Breadth. A small lift per extra chain, capped at four: a protocol live in more places reaches more users.

The board holds every protocol on the snapshot's watchlist (40, at or above $50,000,000 of TVL, recording no token) plus the 160 early pre-token protocols below the floor the model scores highest. No protocol name is ever special-cased: the same function scores every row. The implied value is this radar's own claim, from the snapshot's figures alone; it does not predict whether or when a token is issued. A protocol "records no token" means DefiLlama's record carries none, not that none exists.
